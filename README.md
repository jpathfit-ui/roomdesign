# Room Designer

Place furniture in a photo of your room, true to scale.

- Add a room photo, set the room size with one known measurement, then add furniture with one measurement each.
- Furniture library with types, type-specific measurements, filters, sets and locking.
- Optional link helper (`helper/`) fills in a piece from a product link.
- Saves on the device. Use Menu > Back up to a file for safekeeping.

Live at https://jpathfit-ui.github.io/roomdesign/
